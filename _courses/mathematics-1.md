## Course Description

This course introduces the fundamental principles of reactor physics.

## Learning Objectives

After completing this course, students should be able to:

1. Explain neutron behavior in nuclear reactors.
2. Calculate basic criticality parameters.
3. Apply neutron diffusion theory.
4. Analyze basic reactor kinetics.
