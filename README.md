# Analysis of Nuclear Reactor Operations Group at UNHAN RI

This repository contains the source code for our research group's website at Universitas Pertahanan Republik Indonesia (UNHAN RI).

The website is built using Jekyll, Bootstrap, and Bootswatch.

## Acknowledgements

This website was adapted from the [USLC Lab website](https://uslc-lab.github.io/aboutwebsite.html), which is itself based on the original website developed by [Allan Lab](https://www.allanlab.org/) at Leiden University.

We gratefully acknowledge both research groups for making their website designs and source code publicly available.
